## ⚡ Возможности

- **Распознавание любых тестовых движков**: автоматическое определение вопросов в системах **Moodle**, **iSpring**, **Web-Tutor**, корпоративных LMS и нестандартных одностраничных SPA-приложениях.
- **Верифицированная база вопросов**: проверенные правильные ответы по законодательству РК с точными ссылками на статьи нормативно-правовых актов (НПА).
- **Деликатная подсветка**: маркеры спроектированы так, чтобы не вызывать визуального дискомфорта и не привлекать лишнего внимания со стороны.
- **Горячая клавиша `Alt+Shift+T`**: мгновенное включение и выключение режима распознавания без открытия всплывающего окна.
- **Устойчивость к перефразированию**: алгоритм нормализации русского языка учитывает падежные окончания, склонения, числовые числительные («три года» = «3 года»), а также аббревиатуры (ОПО, БиОТ, МГ, СИЗ, СИЗОД, ГПМ, СЛР).
- **Динамический трекинг (MutationObserver)**: при переходе к следующему вопросу в SPA-тестах подсказка появляется мгновенно без перезагрузки вкладки.
- **Автономность**: работает 100% оффлайн без необходимости подключения к интернету.

## 🛠 Установка в браузер

Расширение работает в **Google Chrome**, **Яндекс.Браузере**, **Microsoft Edge**, **Brave** и любых других браузерах на базе Chromium.

1. Откройте страницу управления расширениями:
   - В Google Chrome / Яндекс.Браузере: `chrome://extensions/`
   - В Microsoft Edge: `edge://extensions/`
2. Включите тумблер **«Режим разработчика»** (*Developer mode*) в правом верхнем углу страницы.
3. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
4. В появившемся окне выбора папки укажите путь к каталогу проекта:
   ```text
   C:\Users\user\Desktop\testHelper
   ```
5. Расширение **«Промбез и БИОТ РК — Помощник ИЦА»** появится в списке установленных.
6. Для удобства нажмите на значок «пазла» в панели браузера и закрепите иконку помощника.

## 🚀 Как пользоваться

### 1. Главная кнопка и горячие клавиши
- Откройте вкладку с тестированием (например, Moodle или корпоративную систему обучения).
- Нажмите иконку расширения и кликните по главной кнопке **«Включить распознавание»**. Кнопка загорится синим цветом с индикатором активности, а статус сменится на **«ВКЛ»**.
- Также включить/отключить помощник можно в любой момент сочетанием клавиш:
  $$\mathbf{Alt + Shift + T}$$
- Если страница теста обновилась или загрузилась динамически, используйте кнопку **«Пересканировать»** (`#rescanBtn`).

### 2. Вкладка «Монитор»
Показывает оперативную сводку по текущей открытой вкладке:
- Название и статус текущей страницы.
- Количество найденных вопросов и подсвеченных ответов.
- Список распознанных вопросов с точным текстом правильного ответа, уровнем уверенности (в %), источником (`База (5/5)` или `6/6 арбитраж НПА РК` / `Live ИИ`) и статьей НПА РК.

### 3. Вкладка «База тестов»
Интерактивный справочник по всей верифицированной базе вопросов:
- **Поиск**: введите ключевые слова, фрагмент вопроса, ответа или статьи закона.
- **Фильтр по категориям**:
  - *Промбез (Закон РК «О гражданской защите» № 188-V)*
  - *БиОТ (Трудовой кодекс РК)*
  - *Магистральные газопроводы (Правила эксплуатации МГ)*
  - *Газоопасные и огневые работы*
  - *Оборудование под давлением (сосуды, манометры)*
  - *Грузоподъемные механизмы (ГПМ)*
  - *Электробезопасность*
  - *Пожарная безопасность*
  - *Работы на высоте и применение СИЗ*
  - *Первая медицинская помощь (СЛР, кровотечения)*
  - *Золотые правила безопасности АО «Интергаз Центральная Азия»*

## 🎨 Режимы отображения подсказок

В верхней части всплывающего окна доступен переключатель заметности метки:

| Режим | Идентификатор | Описание визуального эффекта |
| :--- | :---: | :--- |
| **Еле заметный** *(по умолчанию)* | `subtle` | Едва различимый полупрозрачный оттенок с микро-риской слева толщиной 2px. Идеален для комфортной работы. |
| **Ультра-тихий** | `ultra` | Полностью прозрачный фон. Единственный маркер — микроскопическая точка 4px в верхнем правом углу блока ответа. Не заметен даже при взгляде на экран со стороны. |
| **Чёткий** | `clear` | Контрастная мягкая подсветка с выраженным левым бордюром. Рекомендуется на этапе предварительного обучения и самопроверки. |

## 🔌 Локальный Live-мост

Для вопросов, которых нет в локальной базе, предусмотрен опциональный локальный ИИ-мост:

### Запуск моста
1. Перейдите в папку `bridge`:
   ```cmd
   cd c:\Users\user\Desktop\testHelper\bridge
   ```
2. Запустите командный файл:
   ```cmd
   Start-Bridge.bat
   ```
   *(Либо напрямую: `python bridge_server.py`)*
3. Сервер запустится на адресе `http://127.0.0.1:8765`.

### Возможности моста
- Написан на чистой стандартной библиотеке Python (`http.server.ThreadingHTTPServer`) — **ноль внешних зависимостей pip**.
- Эндпоинт `GET /health` для проверки состояния.
- Эндпоинт `POST /solve` для анализа новых вопросов.
- Включает встроенный детерминированный движок правил РК и поддержку переменных окружения `OPENAI_API_KEY` / `GEMINI_API_KEY`.
- Во вкладке «Настройки» всплывающего окна доступна кнопка **«Проверить связь»**, которая мгновенно валидирует доступность моста.

## 🧪 Тестирование и проверка

### 1. Оффлайн-симулятор тестирования
В состав проекта входит реалистичный тестовый полигон, имитирующий реальные платформы тестирования:
- Файл: `scripts/test_suite.html`
- Для запуска просто откройте файл в браузере Google Chrome или Edge:
  ```text
  c:\Users\user\Desktop\testHelper\scripts\test_suite.html
  ```
- Симулятор включает 4 стиля тестов на одной странице:
  1. **Moodle LMS** (`.que.multichoice`, `.formulation`, `.answer`);
  2. **iSpring Quiz** (`.ispring-question-card`, `.ispring-choice-item`);
  3. **Стандартные веб-формы** с radio и checkbox;
  4. **Динамический SPA-тест** с переключением вопросов кнопкой «Следующий вопрос» (тест `MutationObserver`).

### 2. Запуск автоматических тестов совпадения
Проект использует встроенный тестовый раннер Node.js:
```bash
node --test tests/matcher.test.mjs
```
Тест-сьют проверяет:
- Точное совпадение вопросов;
- Устойчивость к перефразированию и падежным окончаниям;
- Работу с аббревиатурами (ОПО, БиОТ, МГ, СИЗ, СЛР);
- Разрешение неоднозначностей (ИТР раз в 3 года vs рабочие раз в год);
- Числовую и словесную эквивалентность («десять дней» = «10 дней»);
- 0 ложных срабатываний на посторонних вопросах.

### 3. Комплексная проверка сборки и CSP
Скрипт валидации проверяет манифест, заголовки PNG-иконок, базу данных и строгое соответствие правилам CSP Manifest V3:
```bash
python scripts/build_and_verify.py
```

### 4. Генератор иконок
Если требуется пересоздать набор иконок расширения (16x16, 48x48, 128x128):
```bash
python scripts/generate_icons.py
```
*(Поддерживает Pillow и 100% чистый fallback на `zlib`+`struct` без сторонних библиотек)*.

## 🔒 Безопасность и конфиденциальность

- **Строгое соблюдение Manifest V3 CSP**: в коде отсутствуют inline-скрипты, inline-обработчики событий (`onclick` и др.), вызовы `eval()` и динамический код.
- **Локальное хранение**: настройки и история сохраняются исключительно в `chrome.storage.local` вашего браузера.
- **Никаких скрытых отправок данных**: по умолчанию расширение работает строго автономно по встроенной локальной базе вопросов.
- **Поддержка изолированного режима**: расширение может использоваться на защищенных рабочих станциях без доступа к сети Интернет.
